# Smart Calculator

A responsive browser calculator with a modern interface, keyboard controls, and locally saved calculation history.

## Features

- Basic arithmetic: addition, subtraction, multiplication, and division
- Percentage, sign toggle, decimal input, and delete
- Keyboard support (numbers, operators, Enter, Backspace, Escape, and %)
- Recent calculation history with one-click result reuse
- Light/dark theme toggle
- Responsive layout and accessible button labels
- No build tools, frameworks, or server required

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a modern browser.

## Publish with GitHub Pages

1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/(root)`, then save.
5. Wait for GitHub Pages to publish the site.

## Privacy

Calculation history and theme preference are stored in your browser's local storage. They are not sent to a server. Clearing browser site data removes them.

## Files

- `index.html` — page structure
- `style.css` — responsive styling and themes
- `script.js` — calculator behavior and history
